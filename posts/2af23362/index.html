第 6 题：未竟之志

时间限制：1 秒 | 空间限制：512 MB

题目描述

赛场上有 n 根钢栏杆从左到右排成一排，第 i 根钢栏杆的助推值为 a[i]。

在正式投出椅子之前，小鹿可以至多进行一次调整：选择一根钢栏杆，将它从原来的位置取出，再插入到当前序列的任意位置。调整后钢栏杆的相对顺序按新的排列确定。

随后小鹿会选择连续的 5 根钢栏杆作为助跑轨道，并获得这 5 根钢栏杆助推值之和的分数。

请你帮助小鹿求出，他能获得的最大分数。

输入格式

本题包含多组测试数据。第一行包含一个整数 T，表示测试数据的组数。

对于每组测试数据，第一行包含一个整数 n。第二行包含 n 个整数 a[1], a[2], …, a[n]，表示每根钢栏杆的助推值。

数据范围

  • 1 ≤ T ≤ 2 × 10⁵
  • 5 ≤ n ≤ 2 × 10⁵
  • -10⁹ ≤ a[i] ≤ 10⁹
  • 所有测试数据的 n 之和不超过 2 × 10⁵

输出格式

对于每组测试数据，输出一行一个整数，表示小鹿能获得的最大分数。

第 7 题：王国驿道

时间限制：2 秒 | 空间限制：512 MB

题目描述

P 国有 n 座城市，编号为 1, 2, …, n。城市之间建有双向驿道，且任意两座城市之间均可以通过若干条驿道互相到达。

每条驿道都有一个非负的维护费用。由于某种神奇的原因，通过一条驿道所需的通行时间与它的维护费用在数值上相等。

国王认为现有驿道过于冗余，想仅保留其中的一部分驿道以削减维护费用。

对于一份保留驿道的方案，国王提出两个要求：

  1. 任意两座城市之间均可以通过保留的驿道互相到达，且在所有满足该条件的方案中，当前方案的维护费用总和必须最小。
  2. 若 P 国首都为城市 u，则从城市 u 出发，仅通过保留的驿道到达任意城市 v 的最短通行时间，必须等于保留全部驿道时从城市 u 到城市 v 的最短通行时间。

需要判断：当首都 u 分别为城市 1, 2, …, n 时，是否存在一种保留驿道的方案满足上述两个要求。

输入格式

本题包含多组测试数据。

第一行包含一个整数 T，表示测试数据的组数。

对于每组测试数据，第一行包含一个正整数 n。

接下来 n 行，第 i 行包含 n 个整数：

若 a[i][j] = -1，表示城市 i 与城市 j 之间不存在驿道；否则 a[i][j] 表示城市 i 与城市 j 之间驿道的维护费用。

数据范围

  • 1 ≤ T ≤ 500
  • 所有测试数据的 n 之和 ≤ 500
  • -1 ≤ a[i][j] ≤ 10⁶
  • a[i][i] = 0
  • a[i][j] = a[j][i]
  • 任意两座城市之间均可以通过若干条驿道互相到达

输出格式

对于每组测试数据，输出一行长度为 n 的 01 串。

若以城市 i 为首都时存在合法方案，则第 i 个字符为 1，否则为 0。
